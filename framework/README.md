# Temporal Semantic Warehouse Framework

## Specification Track

This directory contains the concise, implementation-oriented specification for the **Temporal Semantic Warehouse (TSW)**. It is separate from the explanatory book under `src/`.

The specification is intended for architects, implementers, reviewers, contributors, and organizations that want to implement or evaluate the framework. It uses normative requirement language (`MUST`, `SHOULD`, `MAY`) where interoperability or semantic correctness matters, and informative examples where implementation choice is intentionally open.

### Current documents

### Status

**v0.1 — Working Draft.** The framework is open for review and refinement. A Working Draft is not a claim of industry-standard status or external consensus.

### Book

For the tutorial, rationale, worked examples, historical comparison, and longer treatment of decision intelligence, see **The Temporal Semantic Warehouse: A Decision Intelligence Architecture for the AI Era** in the repository's mdBook source under [`src/`](../src/). The book is intentionally explanatory; this specification is intentionally prescriptive and concise.
